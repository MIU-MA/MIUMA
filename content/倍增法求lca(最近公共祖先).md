## 什么是 LCA？

在图论和树的结构中，**最近公共祖先**是指在有根树中，找出某两个节点 $u$ 和 $v$ 最近的共同祖先节点。

倍增法是求解 LCA 的经典算法之一。它的核心思想是“二进制拆分”，利用动态规划预处理出每个节点向上跳 $2^j$ 步到达的祖先节点，从而将单次查询的时间复杂度优化到 $O(\log N)$，而预处理的时间复杂度为 $O(N \log N)$。

## 状态转移原理

令 $f_{i,j}$ 为从节点 $i$ 向上走 $2^j$ 步到达的节点（若越界则为 $0$），显然 $f_{i,0}$ 就表示为节点 $i$ 的直接父节点。

由于 $2^j = 2^{j-1} + 2^{j-1}$，我们可以得到状态转移方程：向上跳 $2^j$ 步，等价于先向上跳 $2^{j-1}$ 步，再从那个位置继续向上跳 $2^{j-1}$ 步。

$$f_{i,j} = f_{f_{i,j-1}, j-1}$$

## 核心代码实现

初始化

```c++
const int MAXN = 500005;
vector<int> g[MAXN];
int f[MAXN][22]; // f[i][j] 表示节点i向上跳 2^j 步的祖先
int dep[MAXN];   // 记录每个节点的深度

void initial(){
    for(int j=1;(1<<j)<=n;j++){
        for(int i=1;i<=n;i++){
            f[i][j]=f[f[i][j-1]][j-1];
        }
    }
}
```

但是初始化之前现需要算出每个i的父节点，这里可以采用dfs算

```c++
void dfs(int u,int fa){
    f[u][0]=fa;
    dep[u]=dep[fa]+1;
    for (int v : g[u]) {
        if (v != fa) { // 无向树防死循环
            dfs(v, u);
        }
    }
}
```

之后通过深度计算每个点的lca

```cpp
int lca(int u, int v) {
    // 确保 u 是深度更深（更靠下）的节点
    if (dep[u] < dep[v]) {
        swap(u, v);
    }
    
    //  先让 u 往上跳，跳到和 v 同一高度
    for (int i = 20; i >= 0; i--) {
        if (dep[f[u][i]] >= dep[v]) {
            u = f[u][i];
        }
    }
    
    // 如果此时 u 和 v 重合，说明 v 原本就是 u 的祖先
    if (u == v) {
        return u;
    }
    
    // u 和 v 同步向上跳，无限逼近 LCA，直到跳到 LCA 的正下方
    for (int i = 20; i >= 0; i--) {
        if (f[u][i] != f[v][i]) {
            u = f[u][i];
            v = f[v][i];
        }
    }
    
    // 此时 u 和 v 的父节点就是真正的 LCA
    return f[u][0];
}
```

>[!NOTE]
>**为什么第二个循环结束时返回的是 `f[u][0]`**？
>
>在让 $u$ 和 $v$ 同时向上跳逼近时，判断条件是 `f[u][i] != f[v][i]`。这就意味着：只要跳上去不是同一个节点，我们就大胆跳；如果是同一个节点，说明可能跳到了 LCA 甚至 LCA 的更高层祖先，这时候不跳。
>经过这样的筛选，循环结束时，$u$ 和 $v$ 一定会停在 LCA 的下方。因此，最终返回 $u$ 的父节点 `f[u][0]` 即可。
