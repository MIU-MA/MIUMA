## 什么是 KMP？

在字符串匹配问题中，我们经常需要判断一个模式串 $p$ 是否出现在文本串 $s$ 中，或者统计 $p$ 在 $s$ 中出现了多少次。

如果使用朴素匹配，就需要从文本串的每一个位置开始，逐个字符向后比较。最坏情况下，时间复杂度会达到 $O(nm)$，其中 $n$ 是文本串长度，$m$ 是模式串长度。

KMP 算法的核心思想是：**当匹配失败时，不让模式串从头开始比较，而是利用已经匹配过的信息，直接跳到下一个可能的位置**。这样可以把字符串匹配的总时间复杂度优化到 $O(n+m)$。

## next 数组和 j 的含义

在 KMP 中，最重要的是预处理模式串的 `next` 数组，也常写作 `nxt`。

令 `s2` 为模式串，并且字符串下标从 `0` 开始。

`nxt[i]` 表示：模式串 `s2[0...i]` 的所有真前缀和真后缀中，最长相等部分的长度。

也就是说，`nxt[i]` 记录的是：

$$s2[0 \sim nxt[i]-1] = s2[i-nxt[i]+1 \sim i]$$

这里的“真前缀”和“真后缀”要求不能等于整个字符串本身。

例如字符串 `ababaca`，当已经匹配到前面的 `ababa` 时，如果下一位失配，就不需要完全重来。因为前缀 `aba` 和后缀 `aba` 是相同的，可以直接让模式串跳到长度为 `3` 的位置继续匹配。

在代码中，`j` 可以这样理解：

1. `j` 表示当前已经匹配成功的前缀长度。当 `j = 3` 时，说明模式串的前 `3` 个字符，也就是下标 `0, 1, 2`，已经匹配成功。
2. `j` 也表示下一个需要比较的字符下标。因为下标从 `0` 开始，已经匹配了 `3` 个字符后，下一个要比较的位置正好是 `s2[3]`。

## 状态转移原理

假设当前正在计算 `nxt[i]`，并且已经知道前一个位置的最长匹配长度为 `j = nxt[i - 1]`。

由于 `j` 表示当前已经匹配的前缀长度，所以下一个要比较的位置就是 `s2[j]`。

如果 `s2[i] == s2[j]`，说明原来的最长前后缀可以继续扩展一位，因此：

$$nxt[i] = j + 1$$

如果 `s2[i] != s2[j]`，说明当前长度的前后缀无法继续匹配。这时并不是直接把 `j` 变成 `0`，而是继续向前跳：

$$j = nxt[j - 1]$$

为什么是 `nxt[j - 1]` 呢？因为此时已经匹配成功的是 `s2[0...j-1]`，如果它不能继续匹配，就应该去找这段字符串自己的最长相等前后缀长度。

经过不断回跳，直到找到一个可以继续匹配的位置，或者 `j` 变成 `0` 为止。

## 核心代码实现

下面采用字符串从下标 `0` 开始存储的写法。`s1` 为文本串，`s2` 为模式串。

首先预处理 `nxt` 数组：

```cpp
const int N = 1e6 + 5;
int nxt[N];

void kmp(string s) {
    int j = 0;
    nxt[0] = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) {
            j = nxt[j - 1];
        }
        if (s[i] == s[j]) {
            j++;
        }
        nxt[i] = j;
        maxx = max(maxx, nxt[i]);
    }
}
```

然后用 `nxt` 数组匹配文本串：

```cpp
int j = 0;
for (int i = 0; i < (int)s1.size(); i++) {
    while (j > 0 && s1[i] != s2[j]) {
        j = nxt[j - 1];
    }
    if (s1[i] == s2[j]) {
        j++;
    }
    if (j == (int)s2.size()) {
        cout << i - (int)s2.size() + 2 << '\n';
        j = nxt[j - 1];
    }
}
```

其中 `i - s2.size() + 2` 是把答案转换成从 `1` 开始的下标。因为此时 `i` 是本次匹配在 `s1` 中的结尾位置，并且 `i` 是从 `0` 开始计数的。

如果要写成一份完整模板，可以这样：

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

const int N = 1e6 + 5;
int nxt[N];

void kmp(string s) {
    int j = 0;
    nxt[0] = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) {
            j = nxt[j - 1];
        }
        if (s[i] == s[j]) {
            j++;
        }
        nxt[i] = j;
        maxx = max(maxx, nxt[i]);
    }
}

signed main() {
    string s1, s2;
    cin >> s1 >> s2;

    kmp(s2);

    int j = 0;
    for (int i = 0; i < s1.size(); i++) {
        while (j > 0 && s1[i] != s2[j]) {
            j = nxt[j - 1];
        }
        if (s1[i] == s2[j]) {
            j++;
        }
        if (j == s2.size()) {
            cout << i - s2.size() + 2 << '\n'; // 输出 1 开始的匹配位置
            j = nxt[j - 1];                         // 继续寻找下一次匹配
        }
    }

    for (int i = 0; i < s2.size(); i++) {
        cout << nxt[i] << " ";
    }
    cout << '\n';

    return 0;
}
```

> [!NOTE]
>
> 为什么匹配成功后还要 `j = nxt[j - 1]`？
>
> 当 `j == s2.size()` 时，说明模式串已经完整匹配了一次。此时如果直接把 `j` 清零，就可能漏掉重叠出现的答案。
>
> 例如文本串是 `aaaaa`，模式串是 `aaa`，答案应该有位置 `1, 2, 3`。第一次匹配到位置 `1` 后，模式串的后缀 `aa` 仍然可以作为下一次匹配的前缀继续使用，所以应该跳到 `nxt[j - 1]`，而不是从头开始。

## 深入

[蓝桥杯 2024 国 B\] 最长回文前后缀 - 洛谷](https://www.luogu.com.cn/problem/P10915)

当遇到需要求字符串 $S$ 的最长回文前缀时，可以构造新串：

$$T = S + '\#' + reverse(S)$$

其中 `#` 是分隔符，要求它不能出现在原字符串 $S$ 中。

对拼接后的新串 $T$ 跑一遍 KMP，最后一个位置的 `nxt` 值，就是 $S$ 的最长回文前缀长度。
